- Live listing cards (minimum 50 target in production)
- Nearby area internal links
- Related category links (part-time, freshers, walk-in)

- Job detail pages include `JobPosting` JSON-LD.
- Listing pages include `ItemList` JSON-LD.

## Canonical Rules
- Every landing page must set canonical URL.
- Avoid duplicate pages with the same location intent.
